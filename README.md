# Data-Science-assignment-1
1. Explain the difference between the following data types with examples: Integer (int): Represents whole numbers without a fractional or decimal component. They can be positive, negative, or zero.  Example: x = 25, y = -10Float (float): Represents real numbers with a decimal point. Used for precise measurements or fractional values.  Example: pi = 3.14159, temperature = 98.6String (str): A sequence of characters enclosed in single, double, or triple quotes. Used for text data.  Example: name = "Hemant", college = 'BKBIET'Boolean (bool): Represents one of two values: True or False. Often used in conditional statements and logical operations.  Example: is_student = True, is_graduated = False
